# Credit Risk Assessment Platform
### Turning Credit Data into Smarter Lending Decisions


## Why I Built This Project

Lending organizations face a constant challenge: identifying potential credit defaults while avoiding the rejection of creditworthy customers. Poor risk assessments can lead to financial losses, missed business opportunities, and inconsistent lending decisions.

I built this platform to demonstrate how **data analytics, machine learning, and business intelligence can help organizations make more informed, data-driven credit risk decisions.**

## What It Does

The platform enables users to assess applicant risk, explore customer and loan data, and understand the factors influencing model predictions through an interactive dashboard.

## Business Value

- **Manage risk:** Identify potential default risk earlier in the assessment process.
- **Improve decision-making:** Use data-driven insights to support more consistent lending assessments.
- **Understand performance:** Explore credit trends, portfolio summaries, and model results.
- **Turn data into action:** Present analytical findings through an accessible interface for business users.

## Built With

Python · Scikit-learn · PostgreSQL · SQL · Pandas · Streamlit

The project uses the German Credit dataset and demonstrates an end-to-end analytical workflow, from preparing data and building a predictive model to presenting insights in a deployed application.

## The Bigger Picture

This project reflects my approach to analytics: **understand the business problem, use data to investigate it, and build a solution that makes the findings useful.**
